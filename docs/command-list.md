# Command List

Here is a full list of commands and what they do:

| Command                 | Explanation                                                                                                                                                                                              | When to Use                                                                                                                           |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `postinstall`           | Automatically generates the Prisma client after package installation.                                                                                                                                    | _**There is no need to run this.**_ <br/><br/> This runs automatically after installing dependencies.                                 |
| `dev`                   | Runs multiple development processes concurrently: watches Prisma schema changes, starts Prisma Studio, launches Next.js in dev mode, and runs the email dev server.                                      | Use this command during development when you need to run all related services at the same time.                                       |
| `dev:next`              | Automatically builds the website whenever the code for a page is edited.                                                                                                                                 | _**Not recommended, use `pnpm dev` instead.**_                                                                                        |
| `dev:email`             | Automatically builds E-mails whenever the templates are edited.                                                                                                                                          | _**Not recommended, use `pnpm dev` instead.**_                                                                                        |
| `start`                 | Starts the Next.js production server.                                                                                                                                                                    | Use this command to run your already built production application.                                                                    |
| `build`                 | Performs a series of tasks: installs production dependencies, cleans old build files, builds the Next.js application, generates the Prisma client, deploys database migrations, and generates a sitemap. | Use when preparing your application for production deployment to ensure a complete and optimized build process.                       |
| `prod`                  | Combines the build and start processes: first builds the project and then starts the production server.                                                                                                  | Use for a one-command deployment of your production application.                                                                      |
| `prod:install`          | Installs all necessary dependencies using pnpm.                                                                                                                                                          | Use as part of the production build process to ensure that all packages are correctly installed.                                      |
| `prod:clean`            | Cleans previous build artifacts by removing the `.next` folder.                                                                                                                                          | Use when you need to clear out old build files before starting a fresh production build.                                              |
| `prod:build`            | Builds the Next.js application optimized for production.                                                                                                                                                 | Use to compile and optimize your Next.js application for production deployment.                                                       |
| `prod:sitemap`          | Generates a sitemap for your site using the `next-sitemap` tool.                                                                                                                                         | Use this to create or update your sitemap for better SEO in your production environment.                                              |
| `format:write`          | Automatically formats your code using Prettier, fixes linting issues with Next.js linting, and formats your Prisma schema.                                                                               | Use this command to auto-correct and format your code before commits or as part of your CI process.                                   |
| `format:check`          | Checks if your code adheres to formatting standards defined by Prettier, Next.js linting, and Prisma formatting.                                                                                         | Use to verify that your code meets the project's formatting standards before committing changes or during CI checks.                  |
| `prisma:generate`       | Generates the Prisma client based on your schema.                                                                                                                                                        | Use after modifying your Prisma schema to update the client for proper database interaction.                                          |
| `prisma:generate:watch` | Watches for changes in your Prisma schema and regenerates the Prisma client automatically.                                                                                                               | Use during active development when you are frequently updating your schema and need the client to reflect these changes in real time. |
| `prisma:db:push`        | Pushes your Prisma schema changes directly to the database without creating migrations.                                                                                                                  | Use during development for quickly syncing schema changes (avoid using this in production as it bypasses migrations).                 |
| `prisma:studio`         | Launches Prisma Studio, a visual tool for exploring and managing your database.                                                                                                                          | Use this to inspect, debug, or manage your database in a user-friendly interface during development.                                  |
| `prisma:migrate:dev`    | Creates and applies migrations based on your Prisma schema in development mode.                                                                                                                          | Use when you want to track and apply database schema changes during development using migrations.                                     |
| `prisma:migrate:deploy` | Applies existing migrations in a production environment.                                                                                                                                                 | Use this command to deploy database schema changes safely to production without generating new migrations on the fly.                 |
